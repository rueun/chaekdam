# User Stories

> 책담 V1 의 핵심 사용자 시나리오. 형식: **As a** ... **I want** ... **So that** ... + 완료 조건.

---

## US-1: 회원 가입 / 로그인

**As a** 처음 책담을 방문한 독자
**I want** 이메일·소셜 계정으로 가입하고 로그인할 수 있다
**So that** 내 노트와 토론을 안전하게 보관할 수 있다

**완료 조건**:

- [ ] Supabase Auth 로 이메일·구글·애플 OAuth 로그인 지원
- [ ] 가입 시 닉네임 입력 (1~30자)
- [ ] 로그인 후 홈 화면으로 이동
- [ ] 로그아웃 가능

---

## US-2: 책 검색·선택

**As a** 책을 막 다 읽은 독자
**I want** 책 제목·저자명으로 검색해 책을 선택할 수 있다
**So that** 그 책에 대한 토론·노트를 시작할 수 있다

**완료 조건**:

- [ ] 한국어 책 검색 (네이버 책 API 또는 Google Books)
- [ ] 검색 결과에 책 표지·제목·저자 표시
- [ ] 책 선택 시 메타데이터(제목·저자·장르·요약) 저장
- [ ] 동일 책 재검색·재선택 시 캐시 활용

---

## US-3: 인상 깊은 구절 캡처 (사진)

**As a** 종이책을 읽고 있는 독자
**I want** 인상 깊은 페이지를 사진으로 찍어 올릴 수 있다
**So that** 직접 타이핑하지 않고 빠르게 토론 재료로 만들 수 있다

**완료 조건**:

- [ ] 카메라·갤러리에서 사진 업로드 (`<input capture="environment">`)
- [ ] Supabase Storage 업로드 후 Claude Vision 으로 텍스트 추출
- [ ] 추출된 텍스트 미리보기·수정 가능
- [ ] `ReadingNote.fromPhoto` 로 저장

---

## US-4: 인상 깊은 구절 캡처 (텍스트)

**As a** 전자책을 읽고 있거나 사진 외 방식으로 입력하고 싶은 독자
**I want** 구절을 직접 텍스트로 입력할 수 있다
**So that** 이미 복사해둔 인용문도 바로 노트로 만들 수 있다

**완료 조건**:

- [ ] 텍스트 입력 폼 (1~5000자)
- [ ] zod 스키마로 검증
- [ ] `ReadingNote.fromText` 로 저장

---

## US-5: AI 페르소나 선택

**As a** 토론을 시작하려는 독자
**I want** 오늘의 기분에 맞는 페르소나(학구파 / 캐주얼 / 비평가 등)를 선택할 수 있다
**So that** 같은 책이라도 다른 톤으로 대화할 수 있다

**완료 조건**:

- [ ] 범용 페르소나 3~5개 표시 (학구파·캐주얼·비평가 + 옵션)
- [ ] 각 페르소나에 짧은 설명 노출
- [ ] 기본값(학구파)이 자동 선택돼 있음
- [ ] 선택 안 하면 기본값으로 진행

---

## US-6: AI 토론 시작

**As a** 책·노트·페르소나를 선택한 독자
**I want** 시작 버튼을 누르면 AI 가 첫 응답을 보내주길 원한다
**So that** 자연스럽게 대화가 시작된다

**완료 조건**:

- [ ] 책 메타데이터 + 페르소나 시스템 프롬프트 + 사용자 노트 → Claude API 호출
- [ ] 첫 AI 응답이 채팅 화면에 표시됨
- [ ] `Discussion.start` 로 세션 생성
- [ ] 프롬프트 캐싱으로 책 메타·페르소나는 재사용

---

## US-7: AI 토론 진행

**As a** 토론을 시작한 독자
**I want** AI 와 자연스럽게 메시지를 주고받을 수 있다
**So that** 인상 깊은 구절에 대한 내 생각을 깊이 풀어낼 수 있다

**완료 조건**:

- [ ] 메시지 입력·전송
- [ ] AI 응답 스트리밍 (Server-Sent Events)
- [ ] 메시지 목록이 자동 스크롤
- [ ] 네트워크 에러 시 재시도 가능

---

## US-8: AI 토론 종료

**As a** 토론이 만족스러운 단계에 도달한 독자
**I want** "토론 종료" 버튼으로 세션을 완료할 수 있다
**So that** 회고 단계로 넘어갈 수 있다

**완료 조건**:

- [ ] 채팅 화면에 종료 버튼 노출
- [ ] 종료 시 `Discussion.complete()` 호출
- [ ] 종료 후 자동으로 회고 작성 화면 안내

---

## US-9: 회고 작성

**As a** 토론을 막 마친 독자
**I want** 토론 후 느낀 점·정리·기록을 남길 수 있다
**So that** 내 독서 자산으로 누적된다

**완료 조건**:

- [ ] 회고 노트 작성 폼 (1~10000자)
- [ ] 옵션: 기분(POSITIVE / NEUTRAL / NEGATIVE), 태그(최대 5개)
- [ ] `Reflection.write` 로 저장
- [ ] 작성 스킵 가능 (강제 X)

---

## US-10: 본인 토론·회고 기록 조회

**As a** 누적된 본인의 노트를 다시 보고 싶은 독자
**I want** 내가 작성한 토론·회고 목록을 볼 수 있다
**So that** 과거 생각을 다시 들춰보고 정리할 수 있다

**완료 조건**:

- [ ] 토론 목록 (책별·날짜별 필터)
- [ ] 회고 목록 (태그·기분 필터)
- [ ] 토론 상세 진입 시 메시지 + 회고가 함께 표시됨

---

## 우선순위 (V1 MVP)

| 우선순위      | Story                                                                               |
| ------------- | ----------------------------------------------------------------------------------- |
| **P0 (필수)** | US-1 (인증), US-2 (책 선택), US-4 (텍스트 노트), US-6 (토론 시작), US-7 (토론 진행) |
| **P1 (중요)** | US-3 (사진 노트), US-5 (페르소나 선택), US-8 (토론 종료), US-9 (회고)               |
| **P2 (보강)** | US-10 (기록 조회)                                                                   |

→ P0 만으로도 사용 가능 (텍스트 노트 + 토론). P1 으로 차별화 완성. P2 는 누적된 후 가치 발휘.
