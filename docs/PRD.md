# PRD: 책담 (chaekdam)

## 목표

혼자 책을 읽고 끝내기 아쉬운 순간을 위해, 인상 깊은 구절을 사진 한 장으로 캡처("한 줄 담기")하면 **선택한 페르소나의 AI** 가 그 내용을 바탕으로 1:1 깊이 토론을 시작하고, 담은 **한 줄**과 **독서 기록**이 본인의 독서 자산으로 누적되는 도구.

## 사용자

- 책을 읽지만 함께 이야기 나눌 사람이 없거나, 자기 생각을 정리하고 싶은 한국 독자
- "정독·완독파" 가 아니라 인상 깊은 부분에 머무는 **발췌·정서 위주 독자**
- 모바일에서 책을 찍고 PC / 모바일에서 토론·회고하는 멀티 디바이스 사용자

## 핵심 가치 (포지셔닝)

- **메인: 정서·자기 표현** — "혼자 읽기 외로워서 같이 얘기하고 싶다". 따뜻·공감 위주 톤.
- **보조: 회고·저널링** — 토론 결과를 본인의 독서 자산으로 누적. 재방문 동기.

> AI 토론 시장에서 "학습" 영역은 ChatGPT 등 이미 포화. 정서적 책 친구 + 개인 독서 저널 영역은 비어 있음.

## 핵심 기능

1. **책 / 작가 검색·선택** — 네이버 책 API 기반. 제목·작가·ISBN 검색 후 책장(읽는 중 / 완독 / 읽고 싶은 / 쉬는 중)에 담음.
2. **한 줄 담기 (구절 캡처)** — 사진 촬영·이미지 업로드 또는 텍스트 직접 입력. Claude vision 으로 OCR → 인식된 문장 확인 → 저장. "한 줄" 이 제품의 핵심 단위.
3. **AI 페르소나 선택** — 4종 (소크라테스 / 비평가 / 작가 본인 / 책 동무). 자세한 정책은 아래 참고.
4. **AI 독서 토론 (하이브리드 모드)** — 책 메타데이터(제목·저자·장르·간단 요약) + 사용자 한 줄을 함께 컨텍스트로 사용. 약 5~10턴 깊이 대화. **한 책에 여러 대화방**을 둘 수 있고, 대화방을 시작하면 그 방의 **토론자(페르소나)는 고정**된다. 완독 시 토론자가 먼저 질문하는 "자동 토론 시작"(옵션).
5. **서재 / 책 상태 관리** — 책장 4 상태(읽는 중 · 완독 · 읽고 싶은 · 쉬는 중) + 위시리스트(담아둔 책, 메모·담은 날짜, "지금부터 읽기").
6. **한 줄 모음 + 독서 기록** — 담은 한 줄 전체 컬렉션(밑줄 모음), 월 캘린더·연속일(streak)·연간 컨트리뷰션 그리드·장르/작가 통계, 읽기 세션 기록. **회고·저널링 가치는 별도 회고 노트가 아니라 "한 줄 + 독서 기록" 으로 실현**한다.
7. **한 줄 / 책 공유** — 담은 한 줄이나 책을 링크·이미지(한 장)·SNS(카카오톡·X·스레드·메일)로 내보내기. 인앱 피드·좋아요·팔로우는 없음.

## AI 페르소나 정책

페르소나는 **톤·관점을 가진 토론자 아키타입** 으로 정의. 작가별 상세 큐레이션 파일은 만들지 않는다 — Claude 가 이미 책·작가·시대·문체를 알고 있으므로 페르소나는 톤·관점만 시스템 프롬프트로 지정하고 책 정보는 컨텍스트에서 활용.

- **페르소나 4종**:
  - **소크라테스** · 질문하는 사람 (기본) — 답을 주지 않고 묻기만 해 본인 생각을 끌어냄
  - **비평가** · 분석하는 사람 — 작품의 구조·문체·당대 맥락을 짚어줌
  - **작가 본인** · 쓴 사람의 목소리 — 인터뷰·서신·산문에서 학습한 톤. **사망 작가에 한해** 활성화 (책마다 다름)
  - **책 동무** · 같이 읽는 친구 — 분석하지 않고 함께 반응해주는 가상의 독자
- **작가 본인 페르소나는 사망 작가 한정으로 V1 에 포함** — 저작권·인격권이 소멸했거나 위험이 낮은 사망 작가에 한정해 차별화 요소를 확보. 책별로 활성/비활성이 갈린다.
- **금지**: 생존 작가 페르소나 (저작권·명예훼손·인격권 리스크)

## 토론 모드: 하이브리드

- 책 메타데이터(제목·저자·장르·간단 요약·저자 스타일 — 네이버 책 API + 일부 큐레이션) → 시스템 프롬프트 (1회 주입, 프롬프트 캐싱 활용)
- 사용자 한 줄 / 사진 → 매 토론마다 컨텍스트
- 비용·깊이 균형 — 구절 한정보다 풍부, 책 전체 주입보다 저렴

## MVP 제외 사항

- **북클럽 / 다중 사용자 동시 토론** — 1:1 한정으로 시작 (단, 도메인 모델은 `Participant` 엔티티를 미리 분리해 두어 추후 확장 비용 ↓)
- **결제 / 구독** — 무료 또는 사용량 제한 (Anthropic API 토큰 한도 내)
- **모바일 네이티브 앱** — PWA 로 시작, 사용자 모이면 React Native(Expo) 확장
- **다국어** — 한국어 우선
- **생존 작가 페르소나** — 저작권·인격권 리스크로 제외. (사망 작가 페르소나는 V1 에 포함 — 위 페르소나 정책 참고)
- **인앱 소셜 피드 / 좋아요 / 팔로우** — 제외. 단, 담은 한 줄·책을 외부로 **내보내는 공유(링크·이미지·SNS)는 포함**.
- **다크 모드** — 단일 라이트(페이퍼) 테마로 시작. 다크 모드 미지원 (아래 디자인 참고)

## 디자인

- **단일 라이트(페이퍼) 테마** — 다크 모드 미지원. 종이책의 정서를 닮은 따뜻한 크림/움 표면.
- **미니멀 / 차분** — 책의 정서를 해치지 않는 톤. 따뜻함·공감 분위기 우선.
- **색상**: 웰 크림/페이퍼 중립색 + 딥 포레스트 그린 `#3F6750` **단일 포인트**. 보조색 — 세이지(완독)·클레이(완독/오늘 마커)·톡 블루(AI)·하이라이트 옥로(밑줄). 텍스트는 순검정이 아닌 **따뜻한 근사 검정**.
- **한글 가독성 우선** — Pretendard 전용(본문·제목·인용 모두). 줄 간격·자간 여유 있게.
- **콘텐츠 우선** — 한 줄·인용문·책 표지가 메인, UI 는 받쳐주는 역할.
- **멀티 디바이스** — 모바일(iOS, 탭바+FAB)와 데스크탑 웹(사이드바 내비게이션) 두 키트를 동일한 IA로 제공. 사진 캡처는 모바일, 긴 토론·기록 열람은 웹이 유리.
