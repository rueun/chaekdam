# PRD: 책담 (chaekdam)

## 목표

혼자 책을 읽고 끝내기 아쉬운 순간을 위해, 인상 깊은 구절을 사진 한 장으로 캡처하면 **선택한 페르소나의 AI** 가 그 내용을 바탕으로 1:1 깊이 토론을 시작하고, 토론 후 본인의 **회고·기록**으로 누적되는 도구.

## 사용자

- 책을 읽지만 함께 이야기 나눌 사람이 없거나, 자기 생각을 정리하고 싶은 한국 독자
- "정독·완독파" 가 아니라 인상 깊은 부분에 머무는 **발췌·정서 위주 독자**
- 모바일에서 책을 찍고 PC / 모바일에서 토론·회고하는 멀티 디바이스 사용자

## 핵심 가치 (포지셔닝)

- **메인: 정서·자기 표현** — "혼자 읽기 외로워서 같이 얘기하고 싶다". 따뜻·공감 위주 톤.
- **보조: 회고·저널링** — 토론 결과를 본인의 독서 자산으로 누적. 재방문 동기.

> AI 토론 시장에서 "학습" 영역은 ChatGPT 등 이미 포화. 정서적 책 친구 + 개인 독서 저널 영역은 비어 있음.

## 핵심 기능

1. **책 / 작가 검색·선택** — 외부 도서 API (네이버 책 또는 Google Books) 기반
2. **인상 깊은 구절 캡처** — 사진 업로드 또는 텍스트 직접 입력 (Claude vision 으로 OCR + 토론 시작 한 번에)
3. **AI 페르소나 선택** — 일반 페르소나(학구파 / 캐주얼 친구 등) + **사망 작가 페르소나**
4. **AI 독서 토론 (하이브리드 모드)** — 책 메타데이터(제목·저자·장르·간단 요약) + 사용자 구절을 함께 컨텍스트로 사용. 약 5~10턴 깊이 대화.
5. **토론 회고·기록** — 토론 종료 후 본인의 회고 노트 작성·저장. 본인 독서 노트로 누적·재방문.

## AI 페르소나 정책

- **일반 페르소나** (3~4개): 학구파 독서 친구(기본) / 캐주얼한 친구 / 비평가 등
- **작가 본인 페르소나**: **사망 작가만 허용**
  - 예: 헤르만 헤세, 도스토예프스키, 어니스트 헤밍웨이 등 (저작권 만료 / 인격권 영향 ↓)
  - 작품·문체 특징을 큐레이션해 시스템 프롬프트로 사용
- **금지**: 생존 작가 페르소나 (저작권·명예훼손·인격권 리스크)

## 토론 모드: 하이브리드

- 책 메타데이터(제목·저자·장르·간단 요약·저자 스타일) → 시스템 프롬프트 (1회 주입, 프롬프트 캐싱 활용)
- 사용자 구절 / 사진 → 매 토론마다 컨텍스트
- 비용·깊이 균형 — 구절 한정보다 풍부, 책 전체 주입보다 저렴

## MVP 제외 사항

- **북클럽 / 다중 사용자 동시 토론** — 1:1 한정으로 시작 (단, 도메인 모델은 `Participant` 엔티티를 미리 분리해 두어 추후 확장 비용 ↓)
- **결제 / 구독** — 무료 또는 사용량 제한 (Anthropic API 토큰 한도 내)
- **모바일 네이티브 앱** — PWA 로 시작, 사용자 모이면 React Native(Expo) 확장
- **다국어** — 한국어 우선
- **생존 작가 페르소나** — 영구 미지원 (리스크 존재)
- **소셜 공유 / 피드** — 본인 노트로만 누적 (정서·저널링 가치에 집중)

## 디자인

- **다크모드 우선** — 라이트모드 지원
- **미니멀 / 차분** — 책의 정서를 해치지 않는 톤. 따뜻함·공감 분위기 우선.
- **색상**: 무채색 + 포인트 1가지 (책담 브랜드 색 미정)
- **한글 가독성 우선** — 폰트·줄 간격·자간 신경
- **콘텐츠 우선** — 사진·인용문이 메인, UI 는 받쳐주는 역할
- **모바일 우선** — 사진 캡처는 모바일에서 자주 발생
- **회고 인터페이스** — 토론 종료 후 자연스럽게 회고 노트로 이어지는 흐름
